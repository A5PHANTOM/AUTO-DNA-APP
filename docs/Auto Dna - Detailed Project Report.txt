AUTO DNA — PROJECT REPORT
1. Introduction
Auto DNA is a mobile-based vehicle information and reporting system developed as a college project. The
application allows users to report vehicle incidents such as accidents and damage, which are then verified
by an admin before being made publicly available. The system also includes a marketplace for buying and
selling used vehicles.
The primary goal of Auto DNA is to provide a simple and accessible platform to check the history of a
vehicle using its number plate.

2. Objectives
• To develop a mobile application for vehicle incident reporting
• To implement an admin-based approval system
• To enable vehicle history search using number plate
• To integrate AI-based damage estimation
• To create a simple marketplace for used vehicles

3. Scope of the Project
This project is designed as a prototype system for academic purposes. It runs locally and focuses on
demonstrating core functionalities rather than production-level deployment.

4. System Overview
The system consists of:
• Flutter Mobile Application (Frontend)
• FastAPI Backend (Server-side logic)
• SQLite Database (Data storage)
• Local file storage (Images)
• Streamlit Admin Panel (Admin interface)
